# Bulk CSV templates

Copy a template before editing it. Use the related export command first when
you need the current tenant state, then prepare only the rows you intend to
change. `Action` values are case-insensitive PowerShell comparisons but the
examples use the canonical spelling.

- `bulk-safes.csv`: `Create`, `Update`, or `Delete` safes and assign a managing CPM.
- `bulk-safe-members.csv`: `Add`, `Update`, or `Delete` users/groups on safes.
- `safe-member-permissions.csv`: add only missing members using explicit,
  validated permission columns; compatible with CyberArk API Runner and
  epv-api-scripts naming.
- `bulk-accounts.csv`: `Create`, `Update`, or `Delete` account metadata. It deliberately has no password column; FastPAS never permits secrets in bulk CSV files.
- `platform-account-moves.csv`: change each account's target platform.
- `local-to-domain-accounts.csv`: update username, address, and platform together.
- `outbound-endpoints.csv`: add exact documented SIA or other CyberArk HTTPS endpoints to the connectivity diagnostic.
- `safe-cpm-assignments.csv`: header reference only. Generate the real file with
  **Export verified safe CPM assignments**, then edit only `ManagingCPM` so the
  snapshot hash and conflict checks remain meaningful.
- `discovered-account-decisions.csv`: review, onboard, or ignore pending discovered accounts. Prefer editing the exported discovery workbench.
- `account-links.csv`: create or remove Logon/Reconcile account links.
- `platform-changes.csv`: guarded target-settings changes using documented `Policy/...` or `General/...` paths. Every row requires a current `TargetSettings` hash; this API is self-hosted/version dependent.
- `psm-session-actions.csv`: suspend, resume, or terminate active PSM sessions with a mandatory audit reason.
- `access-request-actions.csv`: create, approve, or reject dual-control requests.
- `application-authentication-changes.csv`: add or delete an Application ID authentication rule. API availability varies by deployment.
- `safe-account-migrations.csv`: input for the migration planner. Apply only the verified plan generated by `safe.migration.plan`.
- `account-safe-transfers.csv`: exactly `OldSafe,NewSafe`. This destructive workflow retrieves and transfers only each account's current secret, preserves its platform and supported metadata, verifies the destination, and then deletes the source. It cannot move password history, audit history, recordings, requests, or account links.

Run write workflows with `-WhatIf` first. Interactive runs require typing
`APPLY`; unattended writes additionally require `-Force -Confirm:$false`.
